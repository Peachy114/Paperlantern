# LanternPaper Version 1

## 1. Main goal

LanternPaper Version 1 should allow creators to:

* Create an account
* Create a novel or comic
* Upload and publish chapters or episodes
* Schedule releases
* View their basic statistics
* Receive comments from readers

Readers should be able to:

* Discover novels and comics
* Read chapters or episodes
* Save reading progress
* Follow works
* Like and comment
* Add works to their library

Version 1 should be simple, reliable, mobile-friendly, and ready for future expansion.

---

# 2. Supported content types

## Novels

Support:

* Original novels
* Light novels
* Web novels
* Short stories
* Serialized fiction

## Comics

Support:

* Manga
* Manhwa
* Manhua
* Webtoons
* Western comics
* Graphic novels

Internally, use two primary work types:

```ts
type WorkType = 'novel' | 'comic'
```

For comics:

```ts
type ComicFormat =
    | 'vertical_scroll'
    | 'page_based'

type ReadingDirection =
    | 'left_to_right'
    | 'right_to_left'
    | 'top_to_bottom'
```

# Version 1 success standard

LanternPaper Version 1 is ready when a creator can complete this full process:

```text
Register
→ Create a novel or comic
→ Add chapters or episodes
→ Save drafts
→ Preview content
→ Publish or schedule
→ Receive readers
→ Receive follows, likes and comments
→ View basic performance
```

A reader must be able to:

```text
Discover a work
→ Open its details
→ Start reading
→ Save progress
→ Follow the work
→ Add it to the library
→ Like and comment
→ Return and continue reading
```

The Version 1 priority is not the number of features.

The priority is making creation, publishing and reading reliable.
